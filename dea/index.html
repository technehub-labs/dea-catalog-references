OpenDEA /dea/<path> resolver

This directory is the static redirect surface for OpenDEA canonical identifiers (RFC 6838 media types, RFC 3986 URI schemes). Each path resolves to the corresponding per-record page on lists.technehub.com via a zero-delay <meta http-equiv="refresh"> redirect, plus a <link rel="canonical"> so search engines treat the target as authoritative.

Path catalogue

dea/uri-schemes/dea (when the IANA-registered dea:// scheme lands; tracked on card #361)

Machine-readable catalogue

The full path catalogue is published as a TSV file: data/paths.tsv — one <tab>-separated row per path, two columns: path and target. Updated every build via scripts/build-html.py.
